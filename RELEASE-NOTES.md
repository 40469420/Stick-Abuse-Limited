# Stick Abuse 3.1.2: The Beating

## Macro editor
- Added Studio and Classic layouts, switchable from the Macros page. Your choice is remembered.
- Studio pairs a compact sequence list and button icons with a selected-step editor for output, hold and delay.
- Move, insert, duplicate or delete steps without opening a wide table.
- Both layouts share the same macro data, recording, import/export, loop settings and copy controls. Switching layouts does not change your profile.
- Layout switching is locked during recording and timeline preview.
- The same editor update is available on the WebHID website.

## Validation
Type checks, production builds, macro editor regression checks and existing desktop tests passed. Browser checks covered shared edits, step controls and recording locks. Controller macro format and playback behavior are unchanged: up to 32 sequential steps. Timeline preview sends no inputs.

Setup includes automatic updates. Portable runs without installation.
